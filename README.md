#  Ball Runner

A simple endless runner game built using **HTML5 Canvas** and **JavaScript**.

Control a bouncing ball, avoid incoming obstacles, and survive as long as possible while your score increases.

---

## Gameplay

* You control a green ball.
* Press **SPACE** to jump.
* Avoid red thorns and blue blocks.
* The game gradually becomes faster as your score increases.
* If you hit an obstacle, the game ends.
* Press **SPACE** again to restart.

---

##  Features

* Smooth canvas-based rendering
* Gravity and jumping physics
* Random obstacle generation
* Increasing difficulty over time
* Score tracking
* Instant restart system
* Lightweight and beginner-friendly code

---

##  Difficulty System

The game automatically becomes harder as your score increases:

* Obstacle speed increases over time.
* Obstacles spawn more frequently.
* Maximum obstacle speed is capped to keep gameplay fair.
